# Aprenda Oxid

A documentação é organizada pelo caminho real de quem está construindo um jogo. Você não precisa conhecer a arquitetura antes de fazer algo funcionar.

## O caminho do zero até um jogo executando

```text
Instalar Oxid → oxid new → projeto → JavaScript → oxid run
                                      │
                                      ▼
                       runtime → ciclo de Entity → renderização
```

## Escolha por onde começar

- **Nunca usei Oxid** → [Instalação](./getting-started/installation) → [Criar projeto](./getting-started/create-project) → [Executar](./getting-started/run-project).
- **Quero entender scripts** → [Scripting](./scripting) → [Ciclo de vida](./scripting/lifecycle) → [Módulos](./scripting/modules).
- **Quero encontrar uma API** → [Referência da API](./api).
- **Quero entender o motor** → [Arquitetura](./architecture).
- **Quero estender o Oxid** → [Módulos nativos](./technical-information/native-modules) → [Metadados da API](./scripting/api-generation).

As páginas conceituais explicam comportamento e conexões; a referência gerada responde quais símbolos existem.
