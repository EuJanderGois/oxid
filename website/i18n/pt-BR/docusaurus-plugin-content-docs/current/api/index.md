# Referência da API

Use os guias de módulo para entender comportamento e exemplos. A referência gerada mostra o inventário exato de funções, tipos, parâmetros e propriedades.

A mesma metadata Rust alimenta `oxid.d.ts` e as páginas web:

```text
metadata → oxid.d.ts
         → referência web
```

Gere as páginas com:

```bash
oxid docs
```

Os módulos documentados incluem `oxid/core`, `oxid/math`, `oxid/color`, `oxid/shapes`, `oxid/input`, `oxid/text` e `oxid/texture`.
